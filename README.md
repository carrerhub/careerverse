# careerverse
CAREERVERSE ialah platform interaktif yang menggabungkan AI, gamifikasi dan Teori Holland. Ia membantu murid meneroka personaliti, mengenal pasti minat, serta menyelesaikan misi simulasi kerjaya. Teknologi AI bertindak sebagai pembantu maya untuk mengesyorkan laluan pengajian dan kerjaya yang tepat demi masa depan yang terancang.
